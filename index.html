Sobre mi

Soy estudiante de tercer año de la Licenciatura en Análisis de Sistemas en la Universidad Nacional de Salta (UNSa).
Me gusta el desarrollo Backend y la arquitectura de software, enfocándome en la creación de sistemas con Java.
Mi perfil incluye el diseño y gestión de bases de datos SQL, además del uso de herramientas como Docker y Git.
Actualmente me dedico a aprender mediante la creacion de proyectos reales, integrando la lógica backend y la persistencia de datos para desarrollar soluciones funcionales, escalables y creativas.

Portafolio Web

Pagina web que funciona como carta de presentacion. Fue hecha en html, css y javascript.
Durante su creacion se tuvo en cuenta la experiencia del usuario, por lo que resulto en una pagina sencilla que permite al cliente acceder a las distintas partes de manera rapida y sencilla, separandola en cuatro secciones importantes: Sobre mi, Proyectos, Tecnologias y Contacto. Tambien se utilizo un servicio de correo externo que permite al usuario comincarse desde la pagina.

HTML CSS Javascript

Infrastructura de 3 capas

Durante un curso se implemento en nube una arquitectura de tres capas en Google Cloud Platform.
Cree una VPC con una subred pública y una subred privada para controlar la exposición de los servicios. Configuré reglas de firewall siguiendo el principio de mínimo privilegio y desplegué un servidor web en la subred pública y un servidor de base de datos en la subred privada, con Route y NAT Cloud para descargar los paquetes necesarios. La comunicación entre aplicación y base de datos se realizó mediante IPs internas, evitando exponer directamente la base de datos a Internet.
